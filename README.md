A Manifest V3 Chrome extension that converts American odds such as `-110` and `+140` into implied
probability. It watches live pages, so odds added or changed by sportsbooks and single-page apps are
converted as they update.

The extension is disabled by default after a fresh install. Open its toolbar popup to enable it
globally or set a local override for the current site.

> For more on implied probability and gambling odds, check out my [blog post](https://www.dannyhines.io/blog/betting-odds-extension).

## Features

- Live `MutationObserver` updates without replacing DOM elements or parsing page text as HTML
- Exact rollback when conversion is disabled
- Rounded explanatory (`+140 (42% implied)`), compact (`+140 (41.7%)`), and probability-only
  (`41.7%`) display modes
- Zero to three decimal places and configurable longshot limits
- Per-site on/off rules stored locally; global display preferences sync through Chrome
- Open shadow-root and related-frame support
- Accessible popup with live conversion count and a quick odds calculator
- Conservative parsing that avoids dates, phone numbers, percentages, CSS units, currency, and
  editable/code regions

The default append mode preserves the original odds. Implied probability includes the sportsbook's
vig and is not the same thing as a fair or no-vig probability.

## Development

Requirements: Chrome 119+ and Node.js 24.15+.

```sh
npm install
npm run check
```

`npm run check` runs strict TypeScript checking, the unit/DOM regression suite, and a clean production
build. Load the generated `dist/` directory from `chrome://extensions` using **Load unpacked**.

To create a Web Store upload after the checks pass:

```sh
cd dist
zip -r ../odds-converter-4.0.0.zip .
```

## Architecture notes

The converter changes only existing `Text.data`, preserving text-node identity for React, Vue, and
other live-rendering frameworks. Each converted node records its original and rendered forms plus an
offset map. That lets the observer distinguish its own asynchronous mutations from site mutations,
reconcile partial updates, and remove only content generated by the extension.

Generated artifacts, dependencies, and release zips are intentionally ignored. Source files,
tests, the manifest, and `package-lock.json` are the reproducible project inputs.
